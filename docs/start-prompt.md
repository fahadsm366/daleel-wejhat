# رسائل Claude Code

## الرسالة الأولى (عند فتح المشروع لأول مرة)

```
أنت تعمل على منصة «دليل الوجهات» في المجلد F:\daleel-wejhat.

اقرأ الملفات بهذا الترتيب:
1. CLAUDE.md — القواعد الثابتة للمشروع.
2. docs/study.md — الدراسة والقرارات المعتمدة.
3. docs/spec.md — المواصفات التفصيلية ونموذج قاعدة البيانات.
4. docs/roadmap.md — خطة التنفيذ.
واطّلع على data/countries.json و design/tokens.css و design/logo.

بعد القراءة، وقبل كتابة أي كود:
1. لخّص لي المشروع في نقاط قصيرة.
2. اذكر أي تعارض أو نقص تراه بين الملفات.
3. اقترح إصدارات Next.js و Prisma و Node التي ستستخدمها، وطريقة تشغيل PostgreSQL على جهازي (Windows).
4. اقترح هيكل مجلدات المشروع، مع إبقاء docs و data و design في مكانها.

انتظر موافقتي، ثم نفّذ المهمة 1 فقط من docs/roadmap.md، وتوقف واشرح:
- ما الذي أنجزته.
- كيف أشغّله وأراه في المتصفح.
- ما الذي أختبره قبل الموافقة.

قواعد العمل طوال المشروع:
- كلّمني بالعربية.
- مهمة واحدة في كل مرة، ولا تنتقل للتالية دون موافقتي.
- بعد كل مهمة أوافق عليها، احفظ التغييرات في git برسالة تصف المهمة.
- لا تغيّر شيئاً في CLAUDE.md أو docs/spec.md دون أن تسألني.
- لا تضع أي مفاتيح أو كلمات مرور داخل الكود؛ استخدم .env.local وأنا أضع القيم بنفسي.
```

## بعد اعتماد كل مهمة

```
المهمة السابقة معتمدة. احفظها في git، ثم نفّذ المهمة التالية من docs/roadmap.md وتوقف واشرح لي ما أنجزته وكيف أختبره.
```

## عند وجود مشكلة (مثال)

```
في صفحة جورجيا، شارة نوع الدخول لا تظهر بجانب اسم الدولة. أصلحها دون تغيير أي شيء آخر، ثم أخبرني بما عدّلته.
```

## عند بدء جلسة جديدة بعد انقطاع

```
نكمل العمل على «دليل الوجهات». اقرأ CLAUDE.md و docs/roadmap.md، وراجع سجل git لتعرف آخر مهمة أنجزناها، ثم أخبرني أين توقفنا وما المهمة التالية. لا تبدأ قبل موافقتي.
```
